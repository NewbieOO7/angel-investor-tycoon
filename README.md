# Angel Investor Tycoon

A game about backing people with terrible ideas. Founders pitch you on napkins, every one has a hidden trait, and rent is due every half-year. Turn $50K into $1M in ten years.

**Play it:** https://newbieoo7.github.io/angel-investor-tycoon/

The whole game is the single file `index.html`. Fonts: Bricolage Grotesque and Caveat, under the SIL Open Font License.
